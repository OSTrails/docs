Code Components
================

The code components take the form of 

* *Tests*: Tests are the code-level instantiations of the objectives defined by a `Metric <../conceptual/metrics-and-benchmarks.html>`_

* *Algorithms*: Algorithms are the code-level instatiations of the objectives and priorities defined by a `Benchmark <../conceptual/metrics-and-benchmarks.html>`_
