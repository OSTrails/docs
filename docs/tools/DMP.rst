OSTrails DMP Tools
===================

DAMAP, DSWizard, and Argos are Data Management Plan (DMP) platforms that work towards implementing the DMP Common Standard (DMP-IF). These tools adopt and use the common concepts, structures, and conventions described in this documentation to enable interoperability and exchange of DMP information.
For tool-specific functionality, implementation details, or support related to DMP-IF, please contact the respective tool providers directly.

    - DAMAP: https://damap.org/
    - DSWizard: https://ds-wizard.org/
    - Argos: https://argos.openaire.eu/portal/
